# 响应式数据看板（HTML + CSS + 原生 JS）

一个适配 **手机 / 平板 / 桌面** 三档宽度的数据看板，纯原生实现，无任何框架与依赖。

## 直接预览

用浏览器打开 `index.html` 即可（或通过任意静态服务器）。拖拽窗口宽度，观察三个断点下的布局变化：

| 宽度 | 布局 |
| --- | --- |
| `<768px` | 卡片单列，侧边栏折叠为顶部栏 + 汉堡菜单 |
| `768–1199px` | 卡片两列，顶部栏导航横排 |
| `≥1200px` | 左侧固定侧栏 + 右侧四列卡片 |

## 文件结构

```
├── index.html    # 语义化结构 + 主题防闪烁内联脚本
├── styles.css    # CSS 变量主题 + 三个媒体查询断点 + 网格布局
├── script.js     # 数据数组循环渲染、主题切换、刷新数据、菜单交互
├── prompt.md     # 实现本项目所用的 Prompt（提交用）
└── README.md
```

## 需求实现对照

1. **三个断点** —— `@media (max-width:…)` 三段式，桌面端额外固定侧栏。 ✅
2. **Grid 自适应** —— 网格使用 `minmax(0, 1fr)` 配合 `repeat` 精确控列，无固定像素宽度。 ✅
3. **无横向滚动** —— `minmax(0,1fr)` + `min-width:0` + `overflow-x:hidden` 兜底，320~1920px 均无横滚。 ✅
4. **JS 数组循环渲染** —— `CARD_DATA` 数组 + `renderCards()` 生成 6 张卡片。 ✅
5. **tabular-nums** —— 数值与涨跌幅均开启，点「刷新数据」数字不抖动。 ✅
6. **CSS 变量 + 深浅主题** —— `data-theme` 切换，localStorage 持久化，默认跟随系统。 ✅
7. **内联 SVG + currentColor** —— 图标全部内联、定尺寸、继承文字颜色。 ✅
8. **语义化标签** —— `h1/h2/h3`、`header/nav/main/section/article`、交互均为 `<button>`。 ✅

## 交互

- **主题切换**：侧栏底部按钮，切换深色 / 浅色，刷新后保持。
- **刷新数据**：右上角按钮，随机微调 6 项指标与迷你趋势图。
- **手机菜单**：顶部汉堡按钮展开 / 收起导航。
